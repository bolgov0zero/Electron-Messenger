Направление

Как Telegram для iOS: плотный список с двумя строками превью, закреплённые на подложке, обои-градиент, время внутри пузыря, имя и статус по центру шапки.

Одинаковые панели

  • Верх: статус-бар 59 + навигация 44 на каждом экране, размытие под системной полосой.
  • Низ: 49 + 34 под индикатор «домой». В переписке то же место занимает поле ввода, внутри меняются только кнопки и текст.
  • В коде: env(safe-area-inset-*), viewport-fit=cover, black-translucent, 100dvh.

Жесты

  • Свайп от левого края — назад.
  • Строка чата: влево — «Без звука» и «Удалить», вправо — «Закрепить».
  • Долгое нажатие на сообщение — меню с реакциями.
  • Свайп по сообщению — ответ (A: показывает время).
  • Шторку закрывает свайп вниз. Клавиатура убирается тапом вне поля или прокруткой.

Что есть в макете

  • Вход, чаты, поиск по чатам, сообщениям и людям, закрепление, без звука, удаление
  • Комнаты с темами, скрытые чаты, чат только для чтения
  • Переписка: ответ, пересылка, правка, реакции, упоминания, вложения, GIF, «Прочитано», индикатор набора
  • Контакты, профиль, блокировки, новая группа, добавление контакта
  • Внешний вид: тема, акцент, фон, узор, размер текста; модули
