Настройки → Звонки → Доступ для других серверов · макет, всё кликабельно

Для каждого сервера создаётся своя пара ключей с названием, которое вы вводите вручную. Любую пару можно скопировать (адрес, ключ и секрет одним блоком), показать или отозвать, остальные продолжают работать. Создание и отзыв перезапускают LiveKit, поэтому окно предупреждает об идущих звонках. Вход на сервер LiveKit настраивается один раз, пароль не сохраняется. Кнопки сверху показывают разные состояния.
