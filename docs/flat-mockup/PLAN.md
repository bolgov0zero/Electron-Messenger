# План переноса дизайна B («Мягкий») в действующие клиенты

Цель: перенести дизайн из макетов `docs/flat-mockup/` в клиенты **в точности**, ничего не потеряв.
Порядок: **этап 1 — мобильный клиент `/m`**, **этап 2 — веб клиент `/chat`**, **этап 3 — Electron `client/`**.
Релизы — только по команде «в релиз». Сейчас: клиент c3.35.1, сервер s2.55.0, коммит `68b9d22a`.

## 1. Решения, которые нужны до старта

| № | Вопрос | Рекомендация |
|---|---|---|
| 1 | **Шрифт.** | **Решено: Inter.** В макетах DM Sans не нёс кириллицу (русский текст рисовался системным шрифтом), поэтому макеты переведены на Inter — теперь они показывают то, что получится в клиентах. Inter уже вшит в клиенты, менять шрифт не нужно. |
| 2 | **Элементы, которые есть не во всех клиентах.** | **Решено:** оформление переносим в каждый клиент только для тех элементов, которые в нём уже есть как функция. Новых функций ради макета не делаем. Известное: блок аккаунтов в баре — только Electron (в веб клиенте нет); в `/m` «Записей» нет — их из переноса исключаем (в макете остались как пример, при приёмке этапа 1 не проверяются); «Скрыть панель» и «Высокая доступность» на входе — только Electron; ссылка на видеозвонок в меню шапки — там, где у пользователя есть право (`can_call_links`). На старте каждого этапа составляется список «есть / нет» по клиенту, приёмка идёт только по тому, что есть. |
| 3 | **Настройки стекла.** «Прозрачность» и «Цветная картинка» теряют смысл. | Убрать из интерфейса; сохранённые значения (`tr`, `amb`) молча игнорировать, без миграции. «Узор» и «Фон переписки» оставить. |
| 4 | **Блюр в мобильном.** Верхний «краевой эффект» `.edge.t` (размытие под статус-баром iOS) — функция, а не украшение: без него белые время и значки не читаются. | **Оставить как есть** (см. раздел 5.1). Остальные размытия убрать. |
| 5 | **Тёмно-синяя тема** есть в клиентах и в макете. | Переносим все три темы × пять акцентов. |
| 6 | **Откат.** | Перед каждым этапом локальный тег-база с именем не `c*`/`v*` (они запускают CI), например `rollback-before-flat-m-c3.35.1-s2.55.0`. |

Как ложится новый дизайн (докованные панели вместо плавающих):
- **Шапка**: строка с кнопками остаётся ровно там же (`top: sat − 6`), фон шапки сплошной и тянется от верха экрана до низа строки (под статус-бар), поэтому заголовок и кнопки не сдвигаются. `.edge.t` остаётся для страниц без шапки (вход, просмотрщик, кадры).
- **Нижняя панель вкладок**: иконки и подписи остаются на прежнем месте относительно `--sab`; сплошной фон тянется от нижнего края экрана (закрывает зону под индикатором «домой») до верха панели. Отступ ленты `sab + 84` не меняется.
- **Поле ввода**: само поле остаётся на `bottom: var(--co)`; докованный фон панели от низа экрана до верха поля + 8–10 px. `--ch` считается по полю, как сейчас.
- **Шторки и клавиатура**: логика `--kbh`/`.kbr`/`.ep` не меняется; меняется только оформление.
- Цвет `html`, `theme-color`, `manifest*.json` (`background_color`), `splash/*.png` приводятся к `--app-bg` вариантов B (светлая / тёмная / тёмно-синяя) — иначе при запуске и в зоне ошибки WebKit видна «чужая» полоса.
- **Приёмка геометрии только на настоящем iPhone** (PWA «на экран Домой», iOS 26): светлая/тёмная/тёмно-синяя; чат с клавиатурой, с панелью смайлов, с закреплённым; список; настройки; шторки; сверка с экраном «Диагностика». Размеры для снимков из Electron: 393×852, 430×932, 375×812 (с эмуляцией `env(safe-area-*)`).

## 7. Как сравнивать «в точности»

1. **Эталон**: по каждой сцене и теме снять макет `shot.js` в `docs/flat-mockup/reference/<платформа>/<сцена>-<тема>.png` (фиксированные размеры: десктоп 1500×960, мобильный 393×852, звонки 1500×1000).
2. **Живой клиент**: те же состояния на тестовых данных, те же размеры, снимок через Electron.
3. **Сравнение**: рядом и попиксельно (скрипт на `pixelmatch`, порог 2%); каждое расхождение — либо исправление, либо запись «принято» с причиной (например, реальные аватарки вместо буквенных, настоящие даты).
4. **Что сравнивается отдельно**: радиусы (замер `getComputedStyle` по списку селекторов из раздела 2.2), размеры кнопок (36 / 40 / 44 / 48), расстояния между элементами, цвета (по токенам), шрифт и размеры текста, состояния hover/active/focus/disabled, тёмная и тёмно-синяя темы, смена акцента.
