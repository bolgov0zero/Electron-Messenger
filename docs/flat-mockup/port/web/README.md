# Снимки для переноса дизайна B в веб клиент /chat

Playwright (Chromium) для Node: `playwright-core@1.60.0` (папка `node_modules` здесь, в git не идёт; если её нет — `npm install` в этой папке). Браузер уже стоит: `~/Library/Caches/ms-playwright/chromium-1223` (тот же, что у python `playwright` 1.60.0).
Стенд: `http://localhost:3999` (запуск при необходимости: `STAND_DIR=<scratchpad>/stand PORT=3999 ../serve.sh start`, затем ~65 с ждать из-за лимита входов). Вход: mivanova / stand-Flat-2026; токен кэшируется в `<scratchpad>/web-session.json` и берётся повторно, пока жив.
Окно 1440×900. API (`lib.js`): `launch()` → `{browser, ctx, page}` (`page.errors` — ошибки консоли и http ≥ 400), `loginLive(page)`, `setThemeLive(page, 'light'|'dark'|'navy', 'teal'|'blue'|'indigo'|'plum'|'amber')`, `openFirstChat(page)`, `openMock(page, theme, accent)`, `shot(page, path, clip?)`.
Быстрый пример: `node snap.js <папка> light navy` — снимки `live-<тема>.png` и `mock-<тема>.png` (открыта первая тема первой комнаты). Свои сценарии — `node -e "const L=require('./lib');(async()=>{const {browser,page}=await L.launch();await L.loginLive(page);await L.setThemeLive(page,'navy','teal');await L.shot(page,'/tmp/x.png');await browser.close()})()"`.
Заметки: в /chat остались только Светлая и Тёмно-синяя (`'dark'` = `'navy'`); в макете `dark` — старая нейтральная тёмная, для сравнения брать `navy`. В живом клиенте акцента `blue` пока нет (ACCENTS в app.js: teal, indigo, plum, amber) — по ключу `blue` остаётся прежний акцент. Сцены макета: `page.evaluate("document.querySelector('#scenes2 [data-s=menu]').click()")`.
