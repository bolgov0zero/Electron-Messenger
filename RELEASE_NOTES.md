Обновлены разделы админ-панели «Файлы», «Объявления», «Уведомления» и «Вебхуки» в едином стиле с остальными страницами.

Файлы: сводка по занятому месту и сроку хранения, фильтры по типу, отправителю и чату, миниатюры картинок, аватарки отправителей, удаление нескольких файлов сразу.

Объявления: журнал с состоянием каждой записи и обратным отсчётом у активной полосы. Окно создания показывает, как объявление увидят люди. Полосу можно снять досрочно — запись остаётся в журнале.

Уведомления: видно, у кого уведомления не включены; фильтр по сервису, проверка и удаление для нескольких подписок сразу.

Вебхуки: активность каждого бота за неделю, отметка «молчит», копирование адреса, смена аватара и выдача нового адреса из меню. После создания показываются адрес и пример запроса.
