Починена прокрутка к последнему сообщению, если это сообщение с видео — раньше лента могла остановиться чуть выше и последнее сообщение пряталось у поля ввода. Такое уже чинили для картинок, теперь то же самое для видео.

Окно просмотра фото и видео на Mac теперь по-настоящему закрывает и строку меню сверху экрана, а не только область под ней. Окно самого чата при этом не разворачивается и не меняется.

В настройках клиента вернулись отступы между кружками выбора цвета акцента.
