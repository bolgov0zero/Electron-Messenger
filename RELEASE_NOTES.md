Добавлена пересылка сообщений. Правый клик на сообщение — кнопка «Переслать». Открывается список чатов и пользователей. После выбора происходит переход в нужный чат с предзаполненной панелью пересылки над полем ввода. Пересланное сообщение отображается с указанием оригинального автора. При пересылке уже пересланного сообщения сохраняется первоначальный автор. Файлы не удаляются, пока на них есть ссылки из пересланных сообщений.
