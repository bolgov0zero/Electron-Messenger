Звонки идут через TCP (TURN по TLS) по умолчанию для серверов звонков с wss://: на Wi-Fi с потерями пакетов видео больше не рассыпается. В настройках звонков переключатель «Идти по UDP» как запасной вариант. Видео в звонке двоих стало чётче (до 3 Мбит/с, 1280×720, 30 кадров), голос чётче. На iPhone и iPad в настройках звонков появился переключатель «Звук через Web Audio» для случая, когда голос идёт сразу из двух динамиков.
