В списке устройств в админке теперь правильно показана система устройства. Раньше перед именем учётной записи стояло слово «Windows» даже для Mac. Приложение присылает свою систему при входе, в строке видно «Приложение · macOS · пользователь bolgov · IP … · зарегистрировано …». У устройств, которые уже были зарегистрированы, система появится после их следующего входа по ключу обновлённым приложением.
