Мобильная версия /m: бейдж даты в переписке теперь прилипает вверху списка при прокрутке, как в клиенте. Исправлен случайный скролл при подгрузке старых сообщений — картинки в истории больше не дёргают ленту в самый низ. Свайп для закрытия шторок настроек теперь срабатывает с первого раза одним движением: сначала докручивает содержимое до верха, затем сразу закрывает, без повторного свайпа.
