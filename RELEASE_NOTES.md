Системные уведомления в чате теперь отличаются от сообщений вебхук-ботов: красный пилл показывается только для пользователя __system__, а не для всех ботов. Системные сообщения полностью неактивны — не добавляются в хранилище msgData, недоступны для пересылки, цитирования и контекстного меню. Вебхук-боты продолжают работать как обычные сообщения.
