Две правки в админ-панели.

При обновлении сервера шаг «Перезапуск службы» больше не остаётся крутиться, когда проверка версии уже прошла. Как только сервер вернулся с новой версией, перезапуск отмечается выполненным.

В сводке раздела «Клиенты» больше не повторяется число: если у каждого человека одно устройство, написано просто «6 человек».
