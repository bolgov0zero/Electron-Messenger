Новая форма пузырей во всех клиентах (Electron, веб и мобильный). Углы скруглены на 17, между соседними сообщениями серии на 5, а у последнего сообщения серии появился хвост. Заливка плотная, без размытия. Реакции теперь лежат внутри пузыря, нижней строкой, время справа в той же строке. Имя отправителя в группе стоит первой строкой внутри пузыря. Строка «Переслано от» выделена цветом, пересланный текст идёт обычным шрифтом.

Скрытый текст «Секрет» выглядит как в Telegram: буквы закрыты мерцающей пылью из точек с мягкими краями, по нажатию текст проявляется. Движение пыли подобрано по записи Telegram. В списке чатов, цитатах, уведомлениях и push скрытый текст показывается рядом брайлевских точек.
