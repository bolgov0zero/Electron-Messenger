Новая страница /beta с кликабельными макетами нового оформления Liquid Glass. По адресу /beta/ открывается макет мобильного клиента: список чатов с фильтрами и папками, переписка, комната с темами, контакты, настройки, профили, медиа, меню сообщения (долгое нажатие), меню чата, шторки и подтверждения. По адресу /beta/desktop.html макет клиента для компьютера. Это только макеты: данных они не читают и ничего не отправляют.
