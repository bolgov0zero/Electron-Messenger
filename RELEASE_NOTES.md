Звонки: доступ к вашему серверу звонков для других серверов. В «Настройки → Звонки» появился раздел «Доступ для других серверов»: для каждого постороннего сервера создаётся своя пара ключей (API key и секрет) с названием, которое вы вводите вручную. Любую пару можно отозвать отдельно, остальные продолжают работать. У каждой пары есть кнопки «Копировать» (адрес, ключ и секрет одним блоком, по паролю администратора), «Данные» и «Отозвать».

Чтобы создавать и отзывать пары, админка один раз настраивает вход на сервер LiveKit: по паролю root (он нигде не сохраняется) на сервер ставится ограниченный ключ, который умеет только добавлять и удалять пары и перезапускать LiveKit. Доступ можно закрыть в любой момент. Создание и отзыв перезапускают LiveKit на несколько секунд, идущие звонки в этот момент прервутся, окно предупреждает об этом.
