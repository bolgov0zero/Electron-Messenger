Сервер стал заметно быстрее, особенно при большой переписке.

Раньше при каждом отправленном сообщении сервер пересчитывал количество непрочитанного для каждого получателя, перебирая всю его переписку целиком. Чем больше накапливалось сообщений, тем дольше это занимало, и всё это время сервер не отвечал никому.

Теперь для каждого человека хранится отметка, докуда он прочитал чат, и непрочитанным считается только то, что новее её. Счёт перестал зависеть от объёма истории.

Плюс сервер больше не считает эти числа для тех, кому они не нужны: они нужны только для уведомлений на телефоне, а раньше считались всем подряд, включая тех, кто сидит в настольном приложении.

Списки чатов и переписка открываются быстрее. На проверочных данных из 60 000 сообщений список чатов стал открываться в шесть раз быстрее, а запас сервера по числу сообщений в секунду вырос в тысячи раз.
