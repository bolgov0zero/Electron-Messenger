Создание чата переделано в отдельное окно с двумя шагами.

Раньше новый чат создавался на месте переписки, а тип нужно было выбрать вкладками «Личный / Группа» ещё до того, как понятно, кого добавляешь. Теперь это отдельное окно.

На первом шаге выбор карточкой: личный чат или группа, с пояснением, чем они отличаются. На втором — список сотрудников с поиском по имени и логину. Для личного чата достаточно нажать на человека, и переписка открывается. Для группы сверху появляются поле названия и аватар, у каждого в списке галочка, внизу видно, сколько человек уже выбрано, и есть кнопка возврата к первому шагу.

Переписка при этом остаётся на экране — окно создания больше не подменяет её собой.
