Клиент: ещё один фикс просмотра видео на Windows — предыдущего исправления (непрозрачное окно) хватило не на всех машинах. Теперь на Windows видео декодируется программно (CPU), минуя аппаратный GPU-декодер, с которым конфликтует часть стороннего софта (Xbox Game Bar, оверлеи видеокарт, RGB-утилиты, программы захвата экрана).
