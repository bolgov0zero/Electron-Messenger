# Приложение Android

Оболочка (WebView) вокруг мобильного клиента `/m`. Интерфейс — страница сервера, поэтому обновляется вместе с сервером. Приложение даёт то, чего нет у веб-приложения:

- аудиозвонок идёт в разговорный динамик (в видеозвонке громкая связь), кнопка «Трубка/Громко» в звонке; у уха экран гаснет датчиком приближения (`CallAudio.kt`);
- уведомления при закрытом приложении: фоновая служба (`NotifyService.kt`) держит соединение `/ws?native=1` и показывает то, что сервер отправил бы в push (`native_push`), а входящие звонки — по событию `call_incoming`;
- служба звонка (`CallService.kt`) не даёт системе отобрать микрофон при свёрнутом приложении.

Адрес сервера спрашивается при первом запуске. В настройках телефона для приложения нужно разрешить уведомления и отключить экономию батареи (приложение само предложит).

## Сборка

Нужны JDK 17 и Android SDK (platform 35, build-tools 34/35). Путь к SDK — в `local.properties` (`sdk.dir=...`).

```bash
./gradlew assembleDebug
```

Готовый файл: `app/build/outputs/apk/debug/app-debug.apk`. Ставится на телефон файлом (разрешите установку из неизвестных источников) или `adb install -r`. Для обновления поверх нужна та же подпись, то есть сборка на том же компьютере.
