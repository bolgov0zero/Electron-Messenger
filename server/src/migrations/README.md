# Миграции схемы

Сервер работает на SQLite (по умолчанию) или PostgreSQL (переменная `DATABASE_URL`).

**PostgreSQL.** Схема живёт здесь, в `pg/NNN_имя.sql`. При запуске применяются все файлы,
которых ещё нет в таблице `schema_migrations`, по порядку номеров; каждый — в своей транзакции.
`001_init.sql` — полная схема на момент появления PostgreSQL. Любое изменение схемы после этого —
только новым файлом с следующим номером; уже применённые файлы не правятся.

**SQLite.** Схема создаётся и дорабатывается в `db.js` (`CREATE TABLE IF NOT EXISTS`, `tryAlter`).
Изменение схемы нужно вносить в оба места: в `db.js` и новой миграцией для PostgreSQL.

База PostgreSQL создаётся в UTF-8 с локалью, знающей кириллицу (например `C.UTF-8` или `ru_RU.UTF-8`):
от этого зависит русская морфология полнотекстового поиска.

Запросы пишутся на общем подмножестве SQL, близком к SQLite; для PostgreSQL их переводит
`dialect.js`. Что не переводится механически (поиск, форматирование дат), пишется отдельно
под каждый движок с проверкой `dal.pg`.
