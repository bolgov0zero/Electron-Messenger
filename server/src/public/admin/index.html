Инструкция по вебхукам

Как это работает
Вебхук — это уникальный URL, привязанный к группе или комнате. Сторонний сервис отправляет на него HTTP-запрос с текстом, и сообщение появляется в чате от имени бота.
GET-запрос (браузер, простые сервисы)
https://ваш-сервер/api/webhooks/TOKEN?text=Текст+сообщения
POST-запрос (curl, скрипты)
curl -X POST https://ваш-сервер/api/webhooks/TOKEN \
  -H "Content-Type: application/json" \
  -d '{"text":"Деплой завершён"}'
Форматирование текста
Поддерживаются HTML-теги:
<b>жирный</b>
<i>курсив</i>
<u>подчёркнутый</u>
<blockquote>цитата</blockquote>
<br> — перенос строки
{"text":"Деплой <b>завершён</b><br>Версия: 1.4.2"}
Zabbix
Administration → Media types → Create media type → Webhook
Параметры:
URL      → https://ваш-сервер/api/webhooks/TOKEN
Message  → {TRIGGER.STATUS}: {HOST.NAME} — {TRIGGER.NAME}
Скрипт:
var params = JSON.parse(value);
var req = new HttpRequest();
req.addHeader('Content-Type: application/json');
var payload = JSON.stringify({ text: params.Message });
req.post(params.URL, payload);
return 'OK';
Ответ сервера
{"ok":true,"message_id":123}   // успех
{"ok":false,"error":"..."}     // ошибка
Лимит: 30 сообщений в минуту на вебхук.
