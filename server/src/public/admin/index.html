Инструкция по вебхукам

Как это работает
Вебхук — это уникальный URL, привязанный к группе или комнате. Сторонний сервис отправляет на него HTTP-запрос с текстом, и сообщение появляется в чате от имени бота.
GET-запрос (браузер, простые сервисы)
https://ваш-сервер/api/webhooks/TOKEN?text=Текст+сообщения
POST-запрос (curl, скрипты)
curl -X POST https://ваш-сервер/api/webhooks/TOKEN \
  -H "Content-Type: application/json" \
  -d '{"text":"Деплой завершён"}'
Форматирование текста
Поддерживаются HTML-теги:
<b>жирный</b>
<i>курсив</i>
<u>подчёркнутый</u>
<blockquote>цитата</blockquote>
<br> — перенос строки
{"text":"Деплой <b>завершён</b><br>Версия: 1.4.2"}
Zabbix
Administration → Media types → Create media type → Webhook
Параметры:
URL      → https://ваш-сервер/api/webhooks/TOKEN
Message  → {TRIGGER.STATUS}: {HOST.NAME} — {TRIGGER.NAME}
Скрипт:
var params = JSON.parse(value);
var req = new HttpRequest();
req.addHeader('Content-Type: application/json');
var payload = JSON.stringify({ text: params.Message });
req.post(params.URL, payload);
return 'OK';
n8n (нода HTTP Request)
Метод — POST. Текст нужно добавлять именно в разделе Send Body, а не Send Query Parameters — POST-запросы сервер читает только из тела, query-строку он смотрит лишь у GET. Body Content Type — JSON, Specify Body — «Using Fields Below» (не «Using JSON» текстом): поле Name text, Value — выражение с исходным полем.
Перед подстановкой замените переносы строк на <br> — обычный «\n» внутри HTML вебхук не превращает в перенос и слепит текст в одну строку:
{{ $json.textHtml.replace(/\n/g, '<br>') }}
Ответ сервера
{"ok":true,"message_id":123}   // успех
{"ok":false,"error":"..."}     // ошибка
Лимит: 30 сообщений в минуту на вебхук.

Как получить ключ Klipy

  1. Откройте кабинет партнёраВойдите или зарегистрируйтесь на partner.klipy.com.
  2. Создайте ключВ разделе «API Keys» создайте платформу (название любое, например «Корпоративный чат»). Появится ключ в статусе Testing.
  3. Скопируйте и сохранитеНажмите «Show key», скопируйте ключ, вставьте его на странице модуля и нажмите «Сохранить». Затем «Проверить ключ» и включите модуль.
  4. Запросите рабочий доступТестовый ключ даёт 100 запросов в час на всех пользователей. Для команды в том же кабинете запросите Production.
Фильтр запрещённых слов и тем настраивается там же, в кабинете Klipy.
